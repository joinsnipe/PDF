# PDF Contigo 2.4.0-beta.10

Activa «Recordar mi conexión en este dispositivo» al configurar tu API. Elige una contraseña de PDF Contigo; en próximas aperturas desbloquea con ella. La API queda cifrada en tu propio perfil. La actualización desde beta 9 necesita pegar la API una vez porque las versiones anteriores no la guardaban.

«Entender mi PDF» entrega un informe por apartados según el documento, con citas plegadas, páginas de referencia y cobertura. Se omiten cifras no presentes en sus citas y se avisa de informes parciales. No verifica toda la interpretación de la IA.

Actualiza el ZIP de escritorio; recargar la web no actualiza Windows/Mac. En Windows extrae todo y ejecuta Instalar_PDF.cmd después de salir de la versión anterior. Android/iOS usan la web instalable: recarga y comprueba beta 10. No es una publicación en las tiendas.

Las pruebas usan respuestas simuladas, cifrado real y claves ficticias. Sin consultas de pago. Se requiere comprobación en dispositivos y con documentos reales. Actions sigue desactivado; esta revisión se compila localmente.
