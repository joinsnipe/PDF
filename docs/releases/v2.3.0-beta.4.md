# PDF Contigo 2.3 beta 4

La aplicación pasa a llamarse **PDF Contigo**. Mantiene el icono blanco y rojo, el enlace web y el repositorio PDF.

- Miniaturas compartidas en las herramientas, selección visual de páginas y giro visible antes de guardar.
- Carga de miniaturas en lotes de doce, orden actualizado al mover archivos y controles legibles en móvil.
- Visor del PDF generado, ajustado al ancho, con zoom, búsqueda y selector si hay varios documentos. También permite revisar el PDF del OCR.
- Firma de aprobación para admitir otras firmas, o **Certificar sin cambios** como primera firma para declarar que no se permiten ediciones ni firmas posteriores.
- La app detecta firmas existentes y bloquea operaciones que modificarían el documento. La lectura y la descarga del original mantienen sus bytes.
- Marca visible compacta: titular y fecha, ajuste del texto y control de tamaño mínimo. En AutoFirma la página y la zona se siguen eligiendo en la aplicación nativa.

**Protección:** la certificación incorpora DocMDP P=1 dentro de los bytes firmados. No hace físicamente imposible modificar una copia; los cambios prohibidos no conservan intacta la certificación. Esta app no valida confianza, revocación ni validez jurídica.

El usuario confirmó que la firma con AutoFirma de beta 3 ya funciona en su Windows. La certificación y el nuevo aspecto de beta 4 todavía requieren comprobación nativa en Windows/Mac. Las pruebas automáticas utilizan certificados ficticios, OpenSSL y componentes simulados; se mantiene la etiqueta beta.

Recarga la web hasta ver **Versión 2.3 beta 4 · AutoFirma**. Para instalaciones locales descarga el ZIP de tu plataforma. Los nombres de los paquetes y los accesos existentes pueden seguir mostrando «PDF» para conservar la compatibilidad.
