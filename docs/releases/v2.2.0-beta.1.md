# PDF 2.2.0-beta.1

Primera distribución pública: 28 herramientas en español con procesamiento local, interfaz blanca y roja y código abierto.

## Descargar

- **windows-x64.zip**: Windows 10/11 x64; extrae todo y abre PDF.cmd.
- **macos-arm64.zip**: Apple Silicon, macOS 13.5+; abre PDF.command.
- **macos-x64.zip**: Intel, macOS 13.5+; abre PDF.command.
- **web.zip**: aplicación construida para alojamiento estático.
- **SHA256SUMS.txt**: hashes de los ZIP.

Android/iPhone: abre https://snipe-pdf.snipex.chatgpt.site y añade PDF a la pantalla de inicio. No hay APK/IPA. En iPhone, Compartir archivo → Guardar en Archivos cuando el navegador lo permita.

Los paquetes incluyen motores, OCR, modelos y runtime para trabajar sin Internet. La web necesita conexión para abrirse. Instrucciones dentro del ZIP en docs/INSTALACION.md.

## Comprobación

La publicación automática exige construcción y pruebas de motores, UI simulada y controladores locales. ZIPs verificados por CRC y SHA-256. Falta la prueba manual de instalación y guardado en dispositivos reales: esta entrega es **beta**, sin firma/notarización propia de aplicación nativa.

El resumen es extractivo; Word exporta texto; firma RSA sin sello de tiempo ni validación de confianza/revocación. Conserva los originales firmados.
