# PDF 2.3.0-beta.1

Esta versión incorpora **AutoFirma como método principal de firma de escritorio** y simplifica el uso de PDF en Windows.

## Novedades

- Elegir el certificado instalado desde AutoFirma sin exportar el P12 ni introducir su contraseña en PDF.
- Seleccionar página y recuadro visible dentro de AutoFirma; recibir y descargar el PDF firmado sin modificar sus bytes.
- Instalación Windows por usuario con `Instalar_PDF.cmd`, iconos en escritorio/Inicio y arranque sin mantener PowerShell abierto.
- Opción **Abrir con → PDF**, contraseña de documento cuando haga falta y botón **Salir de PDF**.
- Correcciones del visor, descargas, contraseñas PDF y compatibilidad del método P12 alternativo.

## Descargar y usar

Windows 10/11 x64: extrae todo `PDF-2.3.0-beta.1-windows-x64.zip`, ejecuta `Instalar_PDF.cmd` y utiliza el icono PDF. También puedes abrir `PDF.cmd` sin instalar.

Mac: elige arm64 para Apple Silicon o x64 para Intel. El lanzador `PDF.command` todavía necesita mantener Terminal abierto. No incorpora «Abrir con» de macOS.

Android/iOS: app web desde el navegador, añadible a la pantalla de inicio. Esta entrega no añade AutoFirma móvil ni «Abrir con» móvil. La web alojada no se actualiza automáticamente al publicar estos paquetes; comprueba su etiqueta de versión.

Para firmar instala [AutoFirma oficial](https://firmaelectronica.gob.es/descargas), abre **Firmar con certificado → AutoFirma** y sigue [la guía](../AUTOFIRMA.md). El paquete web incluye el componente de integración para escritorio.

## Estado de verificación

Construcción completa y 96 pruebas JavaScript + 19 Python aprobadas en Linux: motores, protocolo local, interfaz y controles de escritorio. Paquetes con CRC y manifiesto SHA-256. El cliente AutoScript se ejecuta en pruebas con un WebSocket simulado; la conservación de un CMS ficticio se verifica con OpenSSL.

**Pendiente la prueba nativa completa en Windows/Mac** con el certificado del usuario. La integración evita el lector P12 anterior; no se afirma que ese lector haya dejado de fallar con su archivo. Sigue siendo beta. Código propio MIT; AutoScript y otros componentes conservan sus licencias incluidas.
