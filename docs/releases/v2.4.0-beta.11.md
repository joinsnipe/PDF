# PDF Contigo 2.4.0-beta.11

La contraseña de PDF Contigo para recordar la conexión de IA admite desde **4 caracteres**. Puedes usar una más larga. La clave API sigue siendo la que entrega tu proveedor.

Las contraseñas existentes siguen funcionando. No es necesario borrar ni volver a configurar una conexión guardada.

En web y móvil, recarga hasta ver **2.4 beta 11**. En escritorio local, actualiza el paquete: recargar la web no cambia los archivos instalados. En Windows, sal de PDF, extrae todo el nuevo ZIP y ejecuta `Instalar_PDF.cmd`.

GitHub Actions permanece pausado; los paquetes se preparan localmente.
