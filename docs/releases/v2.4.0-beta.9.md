# PDF Contigo 2.4.0-beta.9

Revisión de lectura con IA, preparada el 18 de octubre de 2026.

## Cambios

- Una sola entrada **Entender mi PDF**, sin botones o selector duplicados Resumir/Explicar. Ofrece ideas principales y, cuando consten, peticiones, documentación y fechas. La alternativa sin IA sigue seleccionando frases localmente.
- Las peticiones de los seis proveedores incluyen fragmentos identificados del texto. El modelo cita identificadores y la app recupera del original sus páginas y citas. Se conserva compatibilidad con respuestas que devuelven citas literales.
- Una referencia no localizable omite solo su punto. Los puntos restantes se entregan con aviso de **informe parcial**, también en el TXT. Si ninguna es válida, se muestra un resultado explícitamente no comprobable con acceso al original; no se muestran las afirmaciones sin respaldo ni se reintenta automáticamente.
- La normalización de citas antiguas admite espacios, comillas tipográficas, guion blando y cortes de palabra al final de línea; no elimina cifras, signos ni acentos. No se aplica coincidencia aproximada ni se busca una página alternativa para justificar una cita.
- La conexión explica que la clave se conserva en memoria mientras esté abierta esa ventana. Cambiar de herramienta o documento la conserva; cerrar, recargar o desconectar la elimina también en escritorio. No se ha añadido almacenamiento de claves sin consentimiento ni persistencia en texto plano.

## Validación y límites

- 35 pruebas de contrato y transporte: seis proveedores, referencias por ID y literales, respuesta parcial, ausencia de referencias, selección de proveedor, claves incompatibles, límites, errores y conectores Windows/Python y Mac/Node.
- 11 pruebas de interfaz seleccionadas: apertura de las 29 herramientas y 10 recorridos de IA. Incluyen PDF ficticio → conector local simulado → respuesta OpenAI → informe parcial descargable, y respuesta sin referencias, sin duplicar solicitudes ni perder la clave entre documentos.
- Compilación del cliente local; ZIP Windows creado localmente, con runtime verificado por SHA-256 y comprobación de integridad del ZIP. No se ejecuta GitHub Actions, no se generan artefactos de Actions y no se usa una clave real ni consumo de API para estas pruebas.
- Sin el documento original ni una respuesta de la cuenta del usuario, no se puede atribuir su discrepancia concreta a una cita o página determinada. Las pruebas reproducen el fallo de descartar un informe completo por una sola referencia. No se afirma haber probado su cuenta ni su PDF.
- Localizar una referencia no verifica la interpretación, la cobertura del informe ni el cálculo de obligaciones. La IA puede equivocarse. El error de referencias ocurre después de recibir una respuesta; no es una prueba de clave incorrecta y la solicitud puede tener coste.
- Verificación de interfaz en DOM simulado, no en dispositivos Windows/móvil reales. El entorno de pruebas emite avisos de fuentes PDF al simular la red; los recursos se incluyen en el paquete. No hay una certificación de accesibilidad.

## Actualizar escritorio

Guarda los resultados y pulsa **Salir de PDF**. Extrae completamente `PDF-2.4.0-beta.9-windows-x64.zip`, abre `PDF/Instalar_PDF.cmd` y después el icono del escritorio. Comprueba **2.4 beta 9** en la cabecera. No se modifican los documentos del usuario. Si el icono es una web instalada desde Chrome/Edge, recarga esa ventana después de actualizar la web.

Esta entrega conserva los workflows pausados. Una actualización del código en GitHub o de la web no reemplaza automáticamente la instalación local ni crea una Release. Los ZIP de Releases anteriores siguen siendo sus versiones originales.
