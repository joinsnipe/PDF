# PDF Contigo 2.4.0-beta.3

Corrección de interfaz: se elimina el acceso de configuración de IA con estrella, que se duplicaba en la parte superior del móvil y en la navegación de escritorio. La cabecera conserva el botón **Configurar IA** con borde rojo.

Aplicado a la web y a los nuevos paquetes Windows/Mac. En la web basta con recargar; las instalaciones locales se actualizan con el ZIP nuevo. Se conserva el funcionamiento de 2.4 beta 2.
