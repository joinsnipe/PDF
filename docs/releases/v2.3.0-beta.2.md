# PDF 2.3 beta 2 — Carga y apertura de AutoFirma

Corrige dos debilidades del conector web detectadas tras el aviso `AF_COMPONENT`: depender del evento de carga completo de un marco con un límite de diez segundos y crear ese marco después del clic que debía abrir AutoFirma.

- El conector se prepara mientras eliges el documento, sin enviarle todavía el PDF ni abrir AutoFirma.
- La disponibilidad se comunica explícitamente y se comprueban origen, ventana y versión.
- Si el navegador necesita un clic nuevo, aparece **Abrir AutoFirma**. Cancelar no inicia la firma.
- Los errores distinguen tiempo de carga, archivo ausente, bloqueo, mezcla de versiones, inicio y conexión local.
- La ayuda explica los permisos de apertura y red local. No se desactiva ninguna comprobación TLS.

La web muestra **Versión 2.3 beta 2 · AutoFirma**. Recarga las pestañas anteriores. Para una instalación local, utiliza el ZIP de esta entrega.

Construcción, 102 pruebas JavaScript y 19 Python. Se cubren HTML real con recursos controlados en JSDOM, protocolo oficial con WebSocket simulado, clic adicional, cancelación/reintento y descarga sin alterar los bytes firmados. **Esto no equivale a una prueba de firma nativa en Windows/Mac**: sigue pendiente con un certificado real. El P12 que fallaba anteriormente no se declara corregido.

Descargas: Windows x64, Mac Apple Silicon, Mac Intel y web. Android/iOS utilizan la web instalable; esta conexión de AutoFirma solo está habilitada en Windows/Mac.
