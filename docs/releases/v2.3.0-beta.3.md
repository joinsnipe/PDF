# PDF 2.3 beta 3 — Corrección del detector de bloqueos

Corrige un falso `AF_COMPONENT_BLOCKED`: la beta 2 podía invalidar AutoFirma cuando el navegador bloqueaba un script ajeno al conector. Solo los recursos necesarios para AutoFirma pueden ahora provocar ese fallo. Las políticas que solo informan tampoco detienen la carga.

- Se mantiene la política CSP restringida y el cliente oficial sin modificar.
- Los fallos reales de archivo, marco, origen e inicialización tienen códigos distintos.
- Cinco pruebas de regresión adicionales; una reproduce el falso aviso con la beta anterior.
- La web muestra **Versión 2.3 beta 3 · AutoFirma**. Recarga la pestaña; las instalaciones locales requieren el ZIP nuevo.

La causa exacta del aviso en el navegador del usuario no se ha podido observar. La firma nativa completa sigue pendiente de validación en Windows/Mac; esta entrega no la da por comprobada. Consulta [la guía de AutoFirma](../AUTOFIRMA.md).
